Build a Progressive Web App (PWA) called RosterFit.

This app is designed specifically for shift workers and must work completely offline.

CRITICAL REQUIREMENTS

- 100% local storage
- No accounts
- No login
- No cloud storage
- No backend server
- No subscriptions
- No analytics
- No tracking
- All user data stored locally on the device using IndexedDB
- User can export all data to JSON
- User can import data from JSON
- App must be installable as a PWA
- Must work offline after first install

DESIGN

- Mobile first design
- Dark mode and light mode
- Modern clean appearance
- Large buttons
- Easy to use when tired or on night shift
- Fast loading

MAIN FEATURES

Dashboard screen

Show:
- Current workout streak
- Longest workout streak
- Today's roster day
- Current roster cycle
- Total workouts completed
- Total cardio sessions completed
- Total rest days completed

Workout Logging

User can create:
- Workout day
- Cardio day
- Planned rest day

Rest days count toward streaks.

Streak System

A streak continues if the day is:
- Workout
- Cardio
- Planned Rest Day

A streak breaks only if the user misses a planned day.

Night Shift Support

Allow user to configure a custom day rollover time.

Example:
- Midnight
- 6am
- 10am

This allows workouts at 2am to count against the previous day.

Exercise Tracking

User can:
- Create exercises
- Edit exercises
- Delete exercises

For every exercise store:
- Weight
- Reps
- Sets
- Notes
- Date

When a workout is logged the app calculates:

Volume =
Weight × Reps × Sets

Personal Bests

Track:
- Highest weight ever lifted
- Highest workout volume
- Longest streak

When a new personal best is achieved show:

"New Personal Best!"

Rest Timer

After a set the user can press:

Start Rest Timer

Options:
- 30 seconds
- 60 seconds
- 90 seconds
- 120 seconds

Visual countdown required.

Display fun comparisons.
